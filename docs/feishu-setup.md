# 飞书开放平台配置（一次性，10-20 分钟）

本 bot 使用飞书**自建应用** + **长连接**模式，无需公网服务器。以下每一步都是必做项，缺一不工作。

## 前置

- 手机/电脑安装飞书
- 一个可登录的飞书账号（个人即可，免费）

## 1. 创建应用

1. 打开 https://open.feishu.cn → 登录 → 进入**开发者后台**
2. 点 **「创建企业自建应用」**（免费；若提示先创建企业/团队，用手机号建一个空的）
3. 应用名称随意（如 `DSH助手`）
4. 进入应用 → 左侧 **「添加应用能力」→「机器人」→ 启用**

## 2. 配置「事件与回调」—— 订阅消息

1. 左侧 **「事件与回调」** → 订阅方式选 **「使用长连接（WebSocket）接收事件」**（推荐）
2. **「事件订阅」** → 添加事件：`im.message.receive_v1`（接收消息）
3. **「回调配置」**（页面下方，不是事件列表！）→ **「卡片回传交互」**（card.action.trigger）→ **开启**（长连接模式无需填回调地址）

> ⚠️ 这两个不是同一个地方：消息事件在「事件订阅」，卡片按钮在「回调配置」。

## 3. 配置「权限管理」—— 必开 3 个

搜索并开通：

| 权限标识 | 用途 |
|---|---|
| `im:message` | 读取/发送消息（基础） |
| `im:message.p2p_msg` | **接收私聊消息**（不加则私聊不推送事件！） |
| `im:message:send_as_bot` | 以机器人身份发消息 |

## 4. 发布版本（关键！）

**每次修改权限/事件/回调后，必须重新发布版本才生效**：

1. 左侧 **「版本管理与发布」→「创建版本」**
2. 版本号递增（1.0.0 → 1.0.1 → …）→ **「申请发布」**（免审核，立即生效）

## 5. 拿凭据

左侧 **「凭证与基础信息」** → 复制 **App ID** 和 **App Secret** → 填入本仓库的 `config.json`：

```json
{
  "appId": "cli_xxxxxxxxxxxxxxxx",
  "appSecret": "xxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "dshBase": "http://127.0.0.1:3080"
}
```

## 6. 验证

```bash
systemctl --user restart dsh-feishu-bot
journalctl --user -u dsh-feishu-bot -f
```

看到 `✅ 飞书长连接已建立` 即成功。

**测试**：
- 私聊机器人：直接发 `你好`（应有回复回执）
- 群聊：拉机器人进群 → `@机器人 你好`

## 常见坑（都踩过）

| 现象 | 原因 | 解决 |
|---|---|---|
| 私聊消息收不到 | 缺 `im:message.p2p_msg` 权限 | 加权限 + 重新发布版本 |
| 卡片按钮点了没反应 | 卡片是**群机器人 webhook** 发的（无回调身份） | 确认卡片由**自建应用**发送（本 bot 即应用身份） |
| 按钮事件回不来 | `card.action.trigger` 未开启或未重新发布 | 回调配置开启 + 重新发布 |
| 审批点了显示"未处理" | bot 拿不到该审批的 rpcId | 确认 bot 事件流连接正常（`📡 事件流已连接`） |
| 修改配置后不生效 | 未重新发布版本 | 飞书要求发布后配置才上线 |
